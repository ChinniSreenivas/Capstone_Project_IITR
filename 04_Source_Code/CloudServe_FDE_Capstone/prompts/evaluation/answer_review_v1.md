# EV-01 v1.0 — Human Answer Review Rubric

Reviewers independently score each response: (1) factual support by retrieved passage, (2) citation correctness, (3) completeness, (4) tone and scope, (5) private-data exposure, (6) unsupported commitments. Mark hallucination if any factual claim is not supported. Mark citation correct only when the cited passage supports the adjacent claim. Escalate disagreements for adjudication. Review at least 50 responses and report inter-rater agreement before making a production claim.
